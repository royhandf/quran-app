# Kebijakan Privasi — Quran Harian

Terakhir diperbarui: 11 November 2026

Quran Harian adalah aplikasi Al-Quran, jadwal sholat, dan dzikir. Kami menghargai privasi Anda. Kebijakan ini menjelaskan data apa yang diakses aplikasi, untuk apa, dan bagaimana penanganannya.

## Data yang Diakses

### Lokasi (akurasi kota)
Aplikasi meminta izin lokasi **akurasi kasar (coarse)** untuk:
- Menentukan kota Anda agar jadwal sholat ditampilkan sesuai wilayah.
- Menghitung arah kiblat.

Koordinat perkiraan dikirim ke layanan API jadwal sholat publik (Aladhan) agar waktu sholat dapat dihitung. Permintaan tidak menyertakan nama, email, atau identitas pribadi lain. Aplikasi tidak memiliki server sendiri dan **tidak menyimpan** lokasi Anda di mana pun selain cache lokal di perangkat.

### Notifikasi & Alarm
Jadwal adzan diproses dan dijadwalkan sepenuhnya di perangkat Anda melalui sistem Android. Tidak ada data yang dikirim ke luar perangkat untuk fitur ini.

### Data yang Disimpan di Perangkat
Penanda bacaan, pengaturan aplikasi, dan cache jadwal disimpan **hanya di perangkat Anda** (penyimpanan lokal Hive). Data ini tidak diunggah, tidak disinkronkan, dan tidak dibagikan. Menghapus aplikasi akan menghapus seluruh data tersebut.

### Jaringan
Aplikasi mengunduh metadata surat/ayat dan audio murottal dari API publik (equran.id, api.aladhan.com) melalui koneksi internet Anda.

## Yang Tidak Kami Lakukan

- Tidak menampilkan iklan.
- Tidak menggunakan layanan analitik pihak ketiga.
- Tidak menjual atau membagikan data kepada pihak ketiga.
- Tidak meminta akun, login, atau data pribadi seperti nama, email, atau kontak.
- Tidak mengakses kontak, SMS, log panggilan, atau file di penyimpanan Anda.
